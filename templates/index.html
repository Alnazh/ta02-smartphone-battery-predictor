📈 Dari Mana Hasil Ini Berasal?

Setiap titik adalah satu pengguna. Semakin lama pakai aplikasi (ke kanan), semakin banyak baterai terpakai (ke atas). Garis merah adalah "garis tebakan" yang dipakai aplikasi ini.

💡 Penjelasan dengan Bahasa Sederhana

Bayangkan kamu mencatat banyak orang: berapa lama mereka main aplikasi dan berapa baterai yang habis. Komputer lalu menarik satu garis lurus yang paling pas melewati catatan-catatan itu. Saat kamu memasukkan durasi baru, aplikasi tinggal melihat di garis itu: "kalau segini menit, baterainya sekitar sekian". Cara ini disebut Regresi Linear.

baterai (mAh) = {{ info.intercept|angka(1) }} {{ "+" if info.coef >= 0 else "-" }} {{ info.coef|abs|angka(3) }} × menit pakai aplikasi {% set contoh = result.durasi if result else v.default_x %}

Contoh dengan {{ contoh|angka }} menit: {{ info.intercept|angka(1) }} {{ "+" if info.coef >= 0 else "-" }} {{ info.coef|abs|angka(3) }} × {{ contoh|angka }} ≈ {{ (info.intercept + info.coef * contoh)|angka }} mAh.

{{ info.coef|angka(3) }} (kemiringan/slope): setiap kamu menambah 1 menit memakai aplikasi, baterai yang terpakai bertambah sekitar {{ info.coef|angka(2) }} mAh. Kalau tambah 1 jam, bertambah sekitar {{ m.slope_jam|angka }} mAh.

{{ info.intercept|angka(1) }} (titik awal/intercept): {% if m.intercept_wajar %} anggap saja ini "pemakaian dasar" HP, misalnya layar menyala, sinyal, dan proses di latar belakang, bahkan saat aplikasi hampir tidak dipakai. {% else %} ini hanya titik awal garis supaya hitungannya pas, jadi tidak perlu diartikan secara harfiah. {% endif %}

R² = {{ info.r2|angka(2) }} ({{ m.r2_persen }}%): sekitar {{ m.r2_persen }}% perbedaan baterai antar-orang bisa dijelaskan oleh lamanya pakai aplikasi. Nilainya 0–100%, makin tinggi makin baik. Kategori: {{ m.r2_label }}.

RMSE = {{ info.rmse|angka(1) }} mAh: rata-rata, tebakan model meleset sekitar segitu dari kenyataan. Makin kecil makin baik.

MAE = {{ info.mae|angka(1) }} mAh: mirip RMSE, tapi lebih ramah terhadap kesalahan besar yang jarang terjadi. Diukur pada {{ info.n_test|angka }} data yang tidak dipakai saat model belajar, jadi lebih jujur.

⚠️ Hal yang Perlu Diingat

  • Model hanya melihat satu hal: lama pakai aplikasi. Kecerahan layar, jenis aplikasi (game vs chat), sinyal, dan usia baterai juga berpengaruh tapi tidak dihitung.
  • Hasilnya perkiraan umum dari data banyak orang, bukan ukuran tepat untuk HP kamu.
  • Model hanya tepercaya untuk durasi {{ v.x_min|angka }}–{{ v.x_max|angka }} menit per hari.
  • "Setara %" dihitung dari kapasitas yang kamu pilih, hanya untuk gambaran.
  • Hubungan dua angka tidak selalu berarti yang satu pasti menyebabkan yang lain, tapi di sini masuk akal karena aplikasi yang dipakai memang menguras daya.
